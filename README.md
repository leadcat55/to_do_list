# Мой день

Открой `index.html` двойным щелчком в браузере. Установка и интернет не нужны.

Добавляй задачи на выбранную дату, меняй название и приоритет, отмечай выполнение. Кольца показывают общий прогресс и выполнение по приоритетам; история — последние семь дней до выбранной даты. Удаление можно отменить.

Данные сохраняются в localStorage текущего браузера. Используй тот же браузер и тот же адрес страницы. Очистка данных браузера удалит записи. Для резервной копии есть экспорт и импорт JSON; импорт заменяет список только после подтверждения. Синхронизации между устройствами нет.

Проверка логики: `node --test tests/model.test.cjs`.

Для локального сервера: `python -m http.server 8080 --bind 127.0.0.1` из этой папки, затем открой http://127.0.0.1:8080. Данные адреса localhost и HTML-файла хранятся раздельно; перенести их можно экспортом/импортом.
